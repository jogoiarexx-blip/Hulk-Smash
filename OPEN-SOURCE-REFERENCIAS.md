# Referências open source — HULK v2.0

- **Three.js CCDIKSolver** — https://threejs.org/docs/pages/CCDIKSolver.html — MIT. Exemplo de IK articulado com limites; o jogo preserva seu solucionador CCD leve existente por compatibilidade com os 108 ossos do GLB.
- **Three.js SkeletonUtils** — https://threejs.org/docs/pages/module-SkeletonUtils — MIT. Avaliado para futuros clipes retargeted; não usado na versão 2.0 porque não há novos clipes fonte licenciados e validados.
- **Yuka** — https://github.com/Mugen87/yuka — MIT. Analisadas as técnicas de FSM, comportamento orientado a objetivos, patrulha e steering. Implementação específica das missões local, sem dependência adicional.
- **Three.js AnimationMixer** — https://threejs.org/manual/pages/game.html — MIT. Mantido o mixer com os dois clipes originais do GLB e camadas procedurais.

A versão 2.0 não inclui arquivos nem assets de terceiros adicionais: todos os módulos incrementais foram escritos especificamente para o jogo. O modelo hulk.glb é o original fornecido pelo usuário.
